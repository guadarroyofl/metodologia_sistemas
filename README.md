# Sistema de Gestión e Inventario Unificado - Caos Vintage

## Descripción
Plataforma de comercio electrónico y gestión interna (Backoffice) para la comercialización de prendas de ropa únicas de segunda mano. Integra un Asistente Virtual ("Personal Shopper") impulsado por IA para la recomendación de outfits según el estilo de cada cliente y un módulo de cálculo de impacto ecológico (ahorro de $CO_2$ y agua). Proyecto desarrollado para la materia Metodología de Sistemas.

## Integrantes
* Nombre y Apellido - Legajo / DNI

## Estructura del Repositorio
* `/docs`: Documentación técnica, diagramas UML, Modelo Entidad-Relación (DER) y normalización 3FN.
* `/database`: Scripts SQL de creación de la base de datos relacional y datos de prueba de catálogo.
* `/src/backend`: Lógica de negocio (MVC), gestión de inventario, cálculo de reportes y servicios del Asistente IA.
* `/src/frontend`: Interfaz de usuario para la tienda pública y el panel de administración.
* `/tests`: Pruebas unitarias e integración de la lógica de catálogo y carrito.
